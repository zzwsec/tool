# NanoPi R3S

一台 R3S，两种打开方式。性能上限取决于硬件，容错上限取决于家庭地位——请量力入座。

| 模式 | 怎么接、负责什么 | 当前状态 / 适用人群 |
| --- | --- | --- |
| **[主路由](main-router/)** | R3S 直连光猫，负责 PPPoE 拨号、DHCP、DNS 与透明代理 | **已竣工**。适合拥有家庭网络最高解释权，且断网后还能从容面对家属质询的人。 |
| **[旁路由](side-router/)** | 保留主路由拨号和 DHCP，R3S 通过 Mihomo 为指定设备提供透明代理 | **新建文件夹**。R3S 炸了就炸了，没走旁路由的设备依旧歌舞升平。 |
